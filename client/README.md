# 마인크래프트 원클릭 접속 클라이언트

친구들에게 이 폴더를 통째로 주면, **`mc-connect.cmd` 를 더블클릭**하는 것만으로 서버에 접속할 수 있습니다.
설치할 것도, 주소를 물어볼 일도 없습니다.

```
client/
├── mc-connect.cmd    ← 친구가 더블클릭하는 파일
├── mc-connect.ps1    ← 실제 동작 (윈도우 기본 파워셸로 실행)
└── server.txt        ← 주소를 알려 주는 고정 URL (배포 전에 채워 두세요)
```

## 어떻게 동작하나

```
server.txt 의 고정 URL  ──▶  { "host": "지금-열린-주소", "port": 25565 }
                                        │
                    cloudflared 자동 내려받기 (처음 한 번)
                                        │
                    cloudflared access tcp 실행
                                        ▼
                    마인크래프트에서 localhost:25565 로 접속
```

터널 주소는 서버를 다시 켤 때마다 바뀝니다. 그래서 **주소를 직접 알려 주지 않고,
"지금 주소가 뭔지" 알려 주는 URL 하나를 고정**해 두고 클라이언트가 그때그때 읽어 옵니다.

## 배포하는 사람이 할 일

1. 서버에서 게시 설정을 한 번 합니다.

   ```bash
   python3 tools/publish-setup.py --gist-id <GIST_ID> --owner <깃허브사용자명>
   ```

   끝나면 클라이언트에 넣을 URL 이 출력됩니다.

2. 그 URL 을 `server.txt` 첫 줄에 넣습니다.

   ```
   https://gist.githubusercontent.com/사용자명/아이디/raw/mc.json
   ```

3. `client/` 폴더를 압축해서 친구들에게 전달합니다.

## 쓰는 사람이 할 일

`mc-connect.cmd` 더블클릭 → 창에 뜨는 `localhost:25565` 를 마인크래프트 서버 주소로 추가.

**게임하는 동안 창을 켜 두어야 합니다.** 닫으면 접속이 끊깁니다.

## 자주 나오는 상황

| 증상 | 원인과 대처 |
|---|---|
| "주소를 받아오지 못했습니다" | 인터넷 문제이거나 `server.txt` URL 오타. 마지막으로 알던 주소로 한 번 더 시도합니다 |
| "연결에 실패했습니다" | 서버가 꺼져 있거나 주소가 막 바뀐 직후. 20초쯤 뒤 다시 실행 |
| 25565 대신 다른 번호가 나옴 | 그 포트를 이미 쓰고 있어서 자동으로 옆 번호를 잡은 것. 화면에 나온 번호로 접속하면 됩니다 |
| 파워셸 실행 정책 오류 | `.cmd` 가 `-ExecutionPolicy Bypass` 로 실행하므로 보통 안 납니다. 직접 `.ps1` 을 실행했다면 `.cmd` 를 쓰세요 |

## 왜 cloudflared 인가

TCP 터널을 무료로 **전송량 제한 없이** 쓸 수 있어서입니다.

| | cloudflared | ngrok | playit.gg |
|---|---|---|---|
| 전송량 | **무제한** | 1GB/월 | 제한 명시 없음 |
| 접속 측 프로그램 | 필요 (이 클라이언트가 대신 처리) | 불필요 | 불필요 |
| 계정 | 불필요 | 필요 + TCP 는 카드 등록 | 필요 |

cloudflared 는 접속하는 쪽에도 프로그램이 필요한 게 유일한 단점인데,
**이 클라이언트가 그 과정을 대신 해 줍니다.** 친구는 그냥 더블클릭만 하면 됩니다.
